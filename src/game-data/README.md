# Extracted Random Dice 2 planner data

This directory contains a normalized, static representation of data tables extracted from the user-supplied Random Dice 2 iOS 1.0.1 package for the Dice Tree planner.

The IPA and its native/modification binaries are not stored in this repository and were not executed. Only table rows required for tree geometry, rank costs, localized effects, dice stats, runes, passives, perks, and projectile-ability values are represented here.

Source snapshot metadata and hashes are documented in `docs/data/ipa-static-analysis-2026-08-15.md`.
