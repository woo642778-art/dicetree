## Strategy notes safe to expose as community guidance

The following are explicitly labelled community guidance in the product:
- early Magic utility routes around Adapt/Summon are described as reusable progression;
- Engineering/Gear investment is repeatedly suggested as an efficient early branch;
- Devour players discuss opening Devour-specific growth routes for ceiling;
- when Devour and Corruption are used together, family-wide Chaos stats can affect both and therefore deserve whole-deck weighting;
- Taeguk should be evaluated as an Order-specialized carry route rather than using a generic global-only optimizer.

These notes affect qualitative recommendation weighting only. They do not alter canonical costs/effects.

## Legacy Random Dice material intentionally excluded

Search results frequently return 2020–2026 Random Dice: Defense guides, including old Taeguk formation guides and old upgrade tables. These are useful only for historical terminology and should not be used as Random Dice 2 cost/effect truth.

## Missing data still requiring current-game evidence

- official names of the blue, red, and prism/cube tree resources;
- full 1→50 / 1→100 cost ladder for rankable stat nodes;
- exact effect text for most overview-only nodes;
- exact family-wide attack-speed formula and stacking semantics;
- exact location/name mapping for every dice icon visible only as artwork;
- whether repeated 100,000-gold capstones use a universal requirement pattern or only happen to share visual cost labels.

V2 is structured so each newly confirmed rank/cost can be inserted independently.
