# Random Dice 2 cost research status — 2026-08-15

This note records the additional research request after V2 approval: fill as much level-by-level cost, resource, dice, and strategy data as can be defended by current evidence.

## Key policy

No missing rank cost is interpolated from neighboring ranks. Exact rank-by-rank costs are canonical only when a current Random Dice 2 screenshot, current community capture, or another current-game source visibly establishes them.

## Current evidence classes

- User full-tree screenshots: strongest topology and visible-cost source.
- User prior node-detail screenshots: strongest exact effect/next-cost source for specific nodes.
- Current Random Dice 2 community posts: strategy and screenshot leads, numerical values promoted only when visible or cross-checked.
- Official store/help pages: product/system context, not rank-cost tables.
- Original Random Dice: Defense material: legacy context only, excluded from Random Dice 2 canonical cost/effect tables.

## Current search outcome

Public web indexing still does not expose a trustworthy complete 1→50 or 1→100 Dice Tree cost ladder. Search results frequently mix Random Dice 2 with Random Dice: Defense. Therefore the site must continue to show exact observed next-cost values and incomplete ladders honestly rather than inventing universal sequences.
